# Capstone 2: Business Analysis with Python

This project analyzes EmporiUm sales data using Python.

The goal is to clean, inspect, and analyze the provided datasets, then compare sales performance between assigned sales territories and present business insights using charts and written conclusions.

This repository includes the Jupyter Notebook, data files, and project materials for the capstone.

## Analysis Focus
This notebook will examine the sales territory managed by `Shruti Reddy`.

The analysis will include:
- data loading and inspection
- data cleaning
- dataset merging
- sales comparison
- category-level performance review
- visualizations created with Matplotlib
- business recommendations based on the results
